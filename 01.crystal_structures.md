## Lattices and bases

A crystal is a lattice plus a basis. The *lattice* is an infinite set of points with
identical surroundings, generated by integer combinations of three primitive vectors:

:::{math}
:label: eq:lattice
\mathbf{R} = n_1 \mathbf{a}_1 + n_2 \mathbf{a}_2 + n_3 \mathbf{a}_3,
\qquad n_i \in \mathbb{Z}
:::

There are only fourteen distinct ways to do this in three dimensions — the Bravais
lattices. Three of them are cubic, and between them they describe most of the metals on
the periodic table.

The cells below set up the geometry. They define symbols for later cells but produce no
figure of their own.

:::{wolfram}
:echo: false

basisVectors["SC"] = {{0, 0, 0}};
basisVectors["BCC"] = {{0, 0, 0}, {1/2, 1/2, 1/2}};
basisVectors["FCC"] = {{0, 0, 0}, {1/2, 1/2, 0}, {1/2, 0, 1/2}, {0, 1/2, 1/2}};

nearestNeighborDistance["SC"] = 1;
nearestNeighborDistance["BCC"] = Sqrt[3]/2;
nearestNeighborDistance["FCC"] = Sqrt[2]/2;

latticePoints[type_, n_] :=
  Union@Select[
    Flatten[
     Table[{i, j, k} + b,
      {i, 0, n}, {j, 0, n}, {k, 0, n}, {b, basisVectors[type]}], 3],
    Max[#] <= n &]
:::

Each conventional cubic cell is drawn as a translucent box with a sphere on every lattice
point it contains:

:::{wolfram}
:echo: true

drawLattice[type_, n_] := Graphics3D[{
   {Opacity[0.12], EdgeForm[Directive[Gray, Thin]], Cuboid[{0, 0, 0}, {n, n, n}]},
   {RGBColor[0.2, 0.4, 0.75], Specularity[White, 40],
    Sphere[#, 0.16] & /@ latticePoints[type, n]}
   },
  Boxed -> False, ImageSize -> 400, ViewPoint -> {1.9, -2.2, 1.4},
  Lighting -> "Neutral"]
:::

Simple cubic puts atoms only at the corners. Body-centred cubic adds one at the cell
centre; face-centred cubic adds one at the centre of each face. Rotate the figure and
step up the number of cells to see how the motifs tile:

:::{wolfram}
:echo: true
:caption: The three cubic Bravais lattices. Drag to rotate; the corner atoms are shared between neighbouring cells.

(* #| label: fig:cubic-lattices *)
Manipulate[
 drawLattice[type, n],
 {{type, "FCC", "lattice"}, {"SC", "BCC", "FCC"}},
 {{n, 1, "cells per edge"}, 1, 3, 1},
 SaveDefinitions -> True]
:::

## Atomic packing factor

How efficiently does each lattice fill space? Treat the atoms as hard spheres that just
touch along the nearest-neighbour direction, so the radius is half that distance. The
atomic packing factor is then the sphere volume per cell divided by the cell volume:

:::{math}
:label: eq:apf
\mathrm{APF} = \frac{N_{\text{cell}} \cdot \tfrac{4}{3}\pi r^3}{a^3},
\qquad r = \tfrac{1}{2} d_{\text{nn}}
:::

:::{wolfram}
:echo: true

packingFactor[type_] :=
  Length[basisVectors[type]] (4/3) Pi (nearestNeighborDistance[type]/2)^3
:::

FCC reaches 0.74 — the densest possible packing of equal spheres, which is why so many
ductile metals adopt it. Simple cubic manages only 0.52 and is correspondingly rare:

:::{wolfram}
:echo: true
:caption: Packing efficiency of the cubic lattices, with atoms drawn at touching radius.

(* #| label: fig:packing-factor *)
Manipulate[
 Column[{
   Graphics3D[{
     {Opacity[0.12], EdgeForm[Directive[Gray, Thin]], Cuboid[]},
     {RGBColor[0.85, 0.45, 0.1], Specularity[White, 40],
      Sphere[#, nearestNeighborDistance[type]/2] & /@ latticePoints[type, 1]}
     },
    Boxed -> False, ImageSize -> 360, ViewPoint -> {1.9, -2.2, 1.4},
    Lighting -> "Neutral", PlotRange -> {{-0.6, 1.6}, {-0.6, 1.6}, {-0.6, 1.6}}],
   Style[
    Row[{"atomic packing factor = ",
      NumberForm[N[packingFactor[type]], {3, 3}]}], 14]
   }, Alignment -> Center],
 {{type, "FCC", "lattice"}, {"SC", "BCC", "FCC"}},
 SaveDefinitions -> True]
:::

Note that @fig:packing-factor draws the spheres at their true touching radius, so the
corner atoms visibly spill outside the cell — each is shared between the eight cells that
meet at that corner.
