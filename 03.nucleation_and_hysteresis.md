## Two equilibria, one system, new test

Each value of the chemical-potential difference $\Delta \mu = \mu_{O} - \mu_{B}$ has an
equilibrium concentration. We probe those concentrations with a lattice-gas Metropolis
model, stepping $\Delta \mu$ across a miscibility gap and letting the system settle at
every step.

The cases below has two disordered phases separated by a miscibility gap — the classic
phase diagram of spinodal decomposition. But the appearance of a new phase carries a
surface-energy penalty, so the equilibrium phase need not appear at all: if there is a
nucleation barrier, the system can sit in a *local* equilibrium while a lower-energy
*global* equilibrium goes unrealised. That gap between local and global equilibrium is
what this chapter makes visible.

:::{wolfram}
:echo: false

Options[sweepBranch] = {"Metropolis Iterations" -> 2 10^6};
sweepBranch[deltas_, 
   OptionsPattern[{latticeGasBulkExchangeSweep, sweepBranch}]] := 
  Module[{config, branch = <||>, configurations = <||>, statistics},
      config = latticeGasRandomConfiguration[64, 64, 1850, 1850];
      Do[
        {config, statistics} = 
     latticeGasBulkExchangeSweep[config, 
      OptionValue["Metropolis Iterations"],
             "energyNearest" -> OptionValue["energyNearest"],
      "energyNextNearest" -> OptionValue["energyNextNearest"],
       "muOrange" -> 1. + deltaMu/2 ,
      "muBlue" -> 1. - deltaMu/2.,
       "inverseTemperature" -> OptionValue["inverseTemperature"],
      "exchangeProbability" -> OptionValue["exchangeProbability"]];
    AssociateTo[configurations, deltaMu -> config];
        AssociateTo[branch, deltaMu -> orangeFraction[config]],
        {deltaMu, deltas}];
    {  branch, configurations}];

## Sweeping from a uniform random configuration

`sweepBranch` takes a list of $\Delta \mu$ values and, at each one, runs enough Metropolis
iterations to be confident the system has reached a (local) equilibrium. After each
equilibrium is found it carries the final configuration forward as the starting point for
the next $\Delta \mu$ — the numerical analogue of a slow experimental sweep. It returns
the final concentrations and the final configurations.

For example, two steps:

:::{wolfram}
:echo: true

{concetrations, configurations} = sweepBranch[{0.2, 0.9},
   "Metropolis Iterations" -> 2 10^6,
    "energyNearest" -> -1.0,
    "energyNextNearest" -> -0.4,
   "inverseTemperature" -> 1/1.2];
:::

:::{wolfram}
:echo: true
:caption: The lattice after equilibrating at $\Delta \mu = 0.2$. Orange and blue are the two species; white sites are vacant.

(* #| label: fig:demo-lattice *)
drawLattice[configurations[0.2], ImageSize -> 400]
:::

The full experiment sweeps 21 values of $\Delta \mu$, evenly spaced from $-2$ to $+2$.
First we start at the negative end and increment towards positive $\Delta \mu$:

:::{wolfram}
:echo: true

{upBranch, upConfigurations} = sweepBranch[deltaMuValues,
   "Metropolis Iterations" -> 2 10^6,
    "energyNearest" -> -1.0,
    "energyNextNearest" -> -0.4,
   "inverseTemperature" -> 1/1.2
   ];
:::

Then we start at the positive end and decrement towards negative $\Delta \mu$:

:::{wolfram}
:echo: true

{downBranch, downConfigurations} = 
  sweepBranch[Reverse[deltaMuValues], 
   "Metropolis Iterations" -> 2 10^6,
    "energyNearest" -> -1.0,
    "energyNextNearest" -> -0.4,
   "inverseTemperature" -> 1/1.2];
:::

Plotting the two branches together:

:::{wolfram}
:echo: true
:caption: Orange fraction against $\Delta \mu$ for an increasing and a decreasing sweep. The two branches do not coincide — the system shows hysteresis.

(* #| label: fig:hysteresis-random *)
llp = ListLinePlot[{upBranch, downBranch}, PlotMarkers -> Automatic,
     Frame -> True,
     FrameLabel -> {"\[CapitalDelta]\[Mu] = \
\!\(\*SubscriptBox[\(\[Mu]\), \(Orange\)]\) - \!\(\*SubscriptBox[\(\
\[Mu]\), \(Blue\)]\)", "orange fraction"},
     PlotLegends -> {"Increasing \[CapitalDelta]\[Mu]", 
    "Decreasing \[CapitalDelta]\[Mu]"},
     PlotRange -> {{-2.1, 2.1}, {-0.05, 1.05}}, ImageSize -> 300, 
  BaseStyle -> {FontSize -> 16}]
:::

There are two concentrations over a range of $\Delta \mu$, so the system cannot be in
global equilibrium on both branches. Stepping through the stored configurations shows
why — drag the slider to walk along a branch, and switch `direction` to compare the
increasing and decreasing sweeps:

:::{wolfram}
:echo: true
:caption: Microstructure along each branch, with the corresponding point marked on the hysteresis loop.

(* #| label: fig:sweep-explorer-random *)
DynamicModule[
 {micro = drawLattice[downConfigurations[[-1]], ImageSize -> 400],
  inset = 
   Show[llp, 
    Graphics[{Black, PointSize[0.05], Point[upBranch[[-1]]]}], 
    ImageSize -> 300],
  upBranchPairs = Transpose[{Keys[upBranch], Values[upBranch]}],
  downBranchPairs = Transpose[{Keys[downBranch], Values[downBranch]}]
  },
 Manipulate[
  Which[
   direction == "down",
   micro = drawLattice[downConfigurations[[i]], ImageSize -> 200];
   inset = 
    Show[llp, 
     Graphics[{Black, PointSize[0.05], Point[downBranchPairs[[i]]]}], 
     ImageSize -> 300];,
   True,
   micro = drawLattice[upConfigurations[[-i]], ImageSize -> 200];
   inset = 
    Show[llp, 
     Graphics[{Black, PointSize[0.05], Point[upBranchPairs[[-i]]]}], 
     ImageSize -> 300]
   ];
  GraphicsRow[{micro, inset}],
  {i, 1, Length[downConfigurations], 1},
  {{direction, "down"}, {"down", "up"}},
  SaveDefinitions -> True
  ]
 ]
:::

Apparently the system needs to overcome a nucleation barrier to reach global equilibrium.

## Sweeping from a configuration containing a nucleation seed

`sweepBranchWithNuclei` is the same experiment with one change: instead of carrying the
previous configuration forward, it restarts each $\Delta \mu$ from a seeded configuration.
At every step the starting lattice looks like this:

:::{wolfram}
:echo: true
:caption: The seed configuration — one small orange nucleus and one small blue nucleus in an otherwise empty lattice.

(* #| label: fig:seed-configuration *)
drawLattice[
 ArrayPad[
  Table[
   Which[(i - 35)^2 + j^2 <= 50, 1, (i + 35)^2 + j^2 <= 50, -1, True, 
    0 ], {i, -100, 100}, {j, -100, 100}], 1
  ]]
:::

Each phase is handed a small seed, so it never has to pay the nucleation barrier. Running
the same two sweeps — increasing $\Delta \mu$:

:::{wolfram}
:echo: true

{upBranchWithNuclei, upConfigurationsWithNuclei} = 
  sweepBranchWithNuclei[deltaMuValues,
   "Metropolis Iterations" -> 2 10^6,
    "energyNearest" -> -1.0,
    "energyNextNearest" -> -0.4,
   "inverseTemperature" -> 1/1.2
   ];
:::

and decreasing $\Delta \mu$:

:::{wolfram}
:echo: true

{downBranchWithNuclei, downConfigurationsWithNuclei} = 
  sweepBranchWithNuclei[Reverse[deltaMuValues], 
   "Metropolis Iterations" -> 2 10^6,
    "energyNearest" -> -1.0,
    "energyNextNearest" -> -0.4,
   "inverseTemperature" -> 1/1.2];
:::

:::{wolfram}

Compare @fig:hysteresis-seeded with @fig:hysteresis-random: removing the nucleation
barrier removes the split between the branches. The seeded microstructures tell the same
story:

This lattice is 201 x 201, so it is drawn with `latticeGasConfigurationPlot` (a raster)
rather than `drawLattice` (one `Disk` per atom). At this size the disks are sub-pixel, and
40,000 of them per frame exceed what the Wolfram Cloud will draw inside a dynamic update —
the panel comes back blank. The raster renders the same colour convention instantly.
